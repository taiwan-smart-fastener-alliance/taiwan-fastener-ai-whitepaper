# 導言：本白皮書之使命與架構說明

### 導言：本白皮書之使命與架構說明

本白皮書旨在為台灣扣件產業（螺絲、螺帽、扣件）提供一份兼具地緣政治戰略高度與工廠產線操作度的數位/AI 轉型實戰指南。面對全球供應鏈重組、ESG 碳關稅壁壘以及結構性缺工的三重夾擊，傳統以「勞力密集」與「師傅經驗」為核心的製造模式已遭逢歷史性瓶頸。本報告不談空泛的科技術語，而是從台灣中小型扣件廠的真實體質出發，梳理出從數據可視化、邊緣運算模型建立，到結合範疇三碳排與動態排程的「全局智造」路徑，協助企業主編列預算、培育人才並對接政府補助資源。
